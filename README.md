# Notebook Organizer

Консольное приложение на Python для создания, просмотра, редактирования, удаления, фильтрации и сохранения заметок.

## Возможности

- Создание заметок.
- Просмотр всех заметок.
- Редактирование заметок.
- Удаление заметок.
- Фильтрация заметок по тегам.
- Фильтрация заметок по дате.
- Отмена последнего действия с помощью стека `UndoStack`.
- Сохранение заметок в JSON-файл.
- Загрузка заметок из JSON-файла.
- Проверка корректности ввода.
- Полиморфизм через классы `TextNote` и `VoiceNote`.

## Структура заметки

Базовая заметка содержит поля:

- `title` — заголовок;
- `text` — текст или описание;
- `tags` — список тегов;
- `date` — дата в формате `ГГГГ-ММ-ДД`.

## Использованные технологии

- Python 3
- ООП
- Стек
- JSON
- Абстрактные классы
- Полиморфизм
- CRUD-операции

## Как запустить

1. Убедитесь, что установлен Python 3.
2. Скачайте файл `main.py`.
3. Откройте терминал в папке проекта.
4. Запустите команду:

```bash
python main.py
```

или:

```bash
python3 main.py
```

## Как пользоваться

После запуска появится меню:

```text
1. Создать заметку
2. Показать все заметки
3. Редактировать заметку
4. Удалить заметку
5. Фильтр по тегу
6. Фильтр по дате
7. Отменить последнее действие
8. Сохранить в JSON
9. Загрузить из JSON
0. Выход
```

Выберите нужный пункт и следуйте инструкциям в консоли.

## Описание классов

### `Note`

Базовый абстрактный класс заметки.

### `TextNote`

Класс текстовой заметки.

### `VoiceNote`

Класс голосовой заметки. Дополнительно содержит длительность в секундах.

### `UndoStack`

Стек для отмены последнего действия.

### `NotebookOrganizer`

Основной класс приложения. Управляет списком заметок и выполняет CRUD-операции.
